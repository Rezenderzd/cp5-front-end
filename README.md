# Mudanças implementadas

## Cor nas classificações
* Fundo das classificações com cor para maior destaque.

## Arredondamento das bordas
* Arredondamento das bordas da tabela e do botão de voltar

## Indicação de peso
* Se o usuário estiver fora do IMC classificado como normal, o sistema pega o imc mais próximo ao imc da pessoa dentro do normal e calcula quanto a pessoa deveria atingir de peso para atingir aquele IMC.
